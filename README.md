# BRFL
In this work, we reformulate SPL fault localization as a structured probabilistic causal inference problem. The proposed approach models features, statements, and execution outcomes within a factor graph that captures structural and dynamic dependencies across product configurations. Instead of relying solely on statistical correlations, we derive heterogeneous prior probabilities from feature--outcome associations and statement-level spectra, incorporating them into Bayesian inference to guide posterior estimation. This integration mitigates variability-induced confounding and enables fault probabilities to be inferred without the need for additional test executions.
